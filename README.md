# minesweeper_tui
A minesweeper game in the terminal

# Description
A minesweeper clone, run in a Terminal User Interface (TUI).
The game is written in pure C with ncurses library.
I'm planning to rewrite it in pure ANSI escape code for rendering in the future.

# Prerequisite
[gcc](https://gcc.gnu.org/install/)
[ncurses](https://invisible-island.net/ncurses/#downloads)

# How to run
- Clone the repository
```bash
git clone https://github.com/GynUnti/minesweeper_tui.git
```
- cd in the directory and run the Makefile   
```bash
cd minesweeper_tui/src/
make
```
- run the program
```bash
./run
```
